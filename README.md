# Portfolio — Vanesa Reche

Sitio estático, 5 páginas HTML autocontenidas (sin build tools). Bilingüe ES/EN con persistencia en `localStorage`.

## Estructura

```
index.html
case-plg.html
case-data-augmentation.html
case-custom-fonts.html
case-mi-argentina.html
images/
```

## Imágenes

Las 16 imágenes ya están incluidas en `images/` con los nombres correctos. No falta nada de tu lado en ese punto.

## Subir a GitHub Pages

1. Creá un repo nuevo en GitHub (público, para que Pages funcione gratis).
2. Subí los 5 archivos `.html` **de a uno por vez** con el uploader web de GitHub — subir varios juntos a veces mezcla nombres/contenidos.
3. Para la carpeta `images/`: entrá al repo, "Add file → Create new file", escribí `images/.gitkeep` como nombre (esto crea la carpeta) y confirmá. Después entrá a esa carpeta y subí ahí tus 4 fotos con esos nombres exactos.
4. Andá a **Settings → Pages**, elegí la rama `main` y la carpeta `/ (root)`, guardá.
5. Tu sitio va a quedar en `https://tu-usuario.github.io/nombre-del-repo/`.

## Editar contenido

Todo el texto (ES/EN) vive en el objeto `translations` al final de cada archivo, dentro de la etiqueta `<script>`. Cambiá el texto ahí — no hace falta tocar el HTML del medio.
